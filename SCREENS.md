
## 🔐 AUTH MODULE

1. **Welcome Screen**

    * "Get Started" or "Login / Sign Up" [Done]

2. **Sign Up Screen**

    * Name, email, password
    * Option to continue with Google (if supported)

3. **Login Screen**

    * Email & password login
    * Forgot password

4. **Password Reset Screen**

---

## 👥 GROUP MODULE

5. **Create Group Screen**

    * Group name, description
    * Auto-generate invite link & code

6. **Join Group Screen**

    * Paste invite code or open from invite link
    * Option to view group details before joining

7. **Group Dashboard Screen**

    * Group name, members list
    * Group leaderboard
    * Group progress through roadmap
    * Group settings (leave, delete, manage members – if owner)

8. **Invite Members Screen**

    * Copy/share invite link or code
    * QR code (optional)

---

## 🧭 ROADMAP MODULE

9. **Roadmap Overview Screen**

    * List of all topics (Arrays, Strings, Trees, etc.)
    * Progress tracking (e.g., % completed)

10. **Topic Detail Screen**

* Concepts under topic
* List of related questions (solved/not solved indicators)

11. **Concept Viewer Screen**

* Concept explanation (markdown or rich text)
* Code snippets, images, notes

---

## 💻 PROBLEM SOLVING MODULE

12. **Problem Detail Screen**

* Title, difficulty, description
* Input/output format
* Constraints, examples

13. **Code Editor Screen**

* In-browser editor with syntax highlighting
* Language selector (e.g., C++, Python)
* Input box (custom test cases)
* Buttons: Run, Submit
* Output panel: stdout, errors, verdict

14. **Submission Result Screen (optional separate)**

* Passed test cases
* Time/space usage
* Points earned

15. **Submission History Screen**

* List of previous attempts for that problem
* Status, language, timestamp
* View code and result
